`@augurproject/design-system` is source-based. Workspace applications can import it directly. Other projects install it from the tarball attached to each GitHub Release (see [Installing the package](#installing-the-package)), or install generated source through the shadcn-compatible registry.

The package exposes these public entry points:

| Entry | What it delivers |
| --- | --- |
| `@augurproject/design-system` | Public React components/patterns, component types/helpers, and font provenance constants/types |
| `@augurproject/design-system/theme.css` | Generated tokens, font-family stacks, typography roles, semantic light/dark roles, and the body, focus and reduced-motion rules. Loads no fonts |
| `@augurproject/design-system/fonts.css` | Optional font faces: Sora 400/600 and Schibsted Grotesk 400 from the pinned `@fontsource` packages. Bundler only |
| `@augurproject/design-system/css/<name>.css` | One stylesheet per component or pattern: `button`, `card`, `dialog`, `input`, `form-field`, `page-header`, `empty-state`. Each depends only on `theme.css` |
| `@augurproject/design-system/icons/<name>.svg` | One SVG file per signal glyph: `arrow-right`, `arrow-up-right`, `check`, `chevron-down`, `plus`, `x`. Stroke in `currentColor`; inline at build time (see [Icons](/foundations/icons)) |
| `@augurproject/design-system/styles.css` | Everything above: `fonts.css`, `theme.css` and every component stylesheet |
| `@augurproject/design-system/tokens.tailwind.css` | Tailwind v4 bridge: `@theme inline` colour utilities for every semantic role, `font-sans` and `font-heading`, and a `dark:` variant |

The `.aug-*` class names are stable API. Before 1.0, renaming one is a minor release with a changelog note. Internal source paths are not public API.

## Cascade layer

Every rule the package ships sits in `@layer augur`, so your CSS overrides it without specificity or order tricks. Unlayered CSS always wins. Layers you declare after `augur` also win.

A layer's position is set by its first appearance. With Tailwind v4, declare the order before importing anything, so Tailwind utilities override Augur rules:

```css
@layer theme, base, augur, components, utilities;
@import "tailwindcss";
@import "@augurproject/design-system/theme.css";
```

Without that statement, `augur` is added after Tailwind's layers and outranks its utilities.

## Dark mode

The theme follows the operating-system preference by default. Set `data-theme="dark"` or `data-theme="light"` on `<html>` or any container to force a scheme there; shadcn's `.dark` class also selects dark.

## Root module

The root module exports the maintained starter components and patterns, including Button, Card, Input, Dialog, PageHeader, EmptyState, and FormField, together with their public types/helpers where applicable.

## Aggregated stylesheet

Most bundled consumers load the full stylesheet once:

```ts
import "@augurproject/design-system/styles.css";
```

## Theme and component files

Import the parts instead when the project loads its own fonts or uses only some components:

```ts
import "@augurproject/design-system/theme.css";
import "@augurproject/design-system/css/button.css";
```

`theme.css` and the component files use relative imports only, so a page without a bundler can link them from `node_modules`:

```html
<link rel="stylesheet" href="node_modules/@augurproject/design-system/src/styles/theme.css">
<link rel="stylesheet" href="node_modules/@augurproject/design-system/src/components/button/button.css">
```

Without `fonts.css`, text falls back to the system sans stack until the project supplies Sora and Schibsted Grotesk.

## Fonts

`fonts.css` imports the pinned `@fontsource` faces. Its bare `@import` specifiers resolve at bundle time (Vite, Astro, webpack), not from a plain `<link>`. Skip it when the project loads its own fonts.

## Installing the package

The package is not on the npm registry yet. Each GitHub Release from `v0.2.0` attaches an `npm pack` tarball. Install it by URL; the package keeps its final name, so imports do not change when it moves to the registry:

```sh
npm install https://github.com/AugurProject/augur-design-system/releases/download/vX.Y.Z/augurproject-design-system-X.Y.Z.tgz
```

The tarball includes the React entry point. Projects that use only the CSS need neither React nor Tailwind.

## Source registry

The registry is a distribution channel, not a second implementation. Generated items are derived from canonical package sources and published under `/r/`.

Start external consumption with `augur-theme`, then install the required component/pattern items. Pin a verified repository ref for reproducibility.

See [Getting started](/getting-started) for the source-install flow. Registry generation and validation are checked in the repository so committed output cannot drift silently from package sources.

## Provenance

Font licenses and source details are recorded in [resources/brand/PROVENANCE.md](https://github.com/AugurProject/augur-design-system/blob/main/resources/brand/PROVENANCE.md). Design-value authority remains in `DESIGN.md`; generated entries are derived outputs.
