## When to use

- First-run or no-data states.
- A region emptied by filters, when the message identifies that cause and offers a way to clear or change the filter.
- Zero search results, when the query and useful corrections remain visible.
- An empty archive or collection where no content exists yet.

<DocExample example={examples.patterns.emptyStateActions} />

## When not to use

- Do not use EmptyState for loading; loading means content may still arrive.
- Do not use it for errors; an error needs cause/recovery language.
- Do not use it as a decorative placeholder when useful summary content can still be shown.
- Do not overload it with several competing actions.

## Anatomy

| Part | Responsibility |
| --- | --- |
| `EmptyState` | Neutral centered region |
| `EmptyStateIcon` | Optional decorative/informative glyph slot |
| `EmptyStateTitle` | State heading |
| `EmptyStateDescription` | Explanation or recovery guidance |
| `EmptyStateActions` | Primary and quiet supporting actions |

The icon tile is 40px and uses the shared square surface radius: 0px. The pattern itself adds no panel background or shadow.

## State-specific guidance

- **No data yet:** explain what will appear here and offer the first useful action.
- **Filtered empty:** name that filters are excluding results and make clearing/changing them easy.
- **Zero search results:** keep the search context visible and suggest corrections or broader terms.
- **No available action:** omit the action row rather than inventing a command.

## Accessibility

- Use a real heading level appropriate to the surrounding outline; `h2` is the default.
- Decorative glyphs should be hidden from assistive technology. Informative imagery must be labeled.
- Actions are real Buttons and keep their keyboard/focus behavior.
- Empty, loading, and error states must be named in text; visual treatment alone is not sufficient.

## API

```tsx
import {
  EmptyState,
  EmptyStateIcon,
  EmptyStateTitle,
  EmptyStateDescription,
  EmptyStateActions,
} from "@augurproject/design-system";
```

Every part accepts native attributes for its element, `className`, and a React 19 ref prop. `EmptyStateTitle` accepts `headingLevel` when the default `h2` does not match the surrounding outline.

## Related components and patterns

Use [Button](/components/button) for recovery/creation actions. An EmptyState may sit inside [Card](/components/card) when the surrounding region is already a meaningful panel; it should not add another surface of its own.

## Verification

Repository tests cover heading semantics, neutral theme roles, Button composition, long-copy behavior, responsive layout, square icon geometry, and axe findings.

## Design rationale

The pattern distinguishes state through explicit language rather than decorative emptiness. A neutral container prevents an empty region from competing with real content elsewhere on the page, while the primary Button remains the only strong intent signal when one exists.
