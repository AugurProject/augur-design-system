Augur's identity is fixed supplied artwork, not live text styled to resemble a logo. The repository carries the complete raster logo family and REP token recovered losslessly from the canonical brand foundation PDF while the original Illustrator/SVG masters remain unavailable.

## Logo family

Use the horizontal lockup by default. Use the vertical lockup only when width is genuinely constrained. Use the glyph alone only where the surrounding context already establishes the name Augur.

**Black means Augur Navy `#0E0E21`, not `#000000`.** Color is the normal choice on Paper or White. Reversed is the normal choice on Navy, Raised, or another approved dark brand surface. Black and White are single-tint production/supporting variants rather than substitutes for the two-tint defaults.

## REP token

The [canonical REP token PNG](/brand/token/rep.png) is separate from the Augur glyph. Its circular navy field is part of the asset. Do not crop the field away, recolor the icon, or use the REP token as a navigation icon or decorative app mark.

## Favicon and app icon

The one approved exception is the browser favicon and touch icon. The token icon published at augur.net is the approved icon for Augur web properties. It carries its own navy field, so the glyph's 50px minimum does not force a redraw at tab size. Use these files unchanged:

| File | Size | Use |
| --- | --- | --- |
| [favicon.svg](/brand/icon/favicon.svg) | 96×96 viewBox | Modern browsers |
| [favicon-32.png](/brand/icon/favicon-32.png) | 32×32 | PNG fallback |
| [apple-touch-icon.png](/brand/icon/apple-touch-icon.png) | 180×180 | iOS home screen |

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="icon" href="/favicon-32.png" type="image/png" sizes="32x32" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" sizes="180x180" />
```

The icon reads the same in light and dark browser chrome because the navy field travels with it; do not swap variants by theme. Keep the icon to these slots; it does not replace the logo in page headers.

## Clearspace and minimum size

Use **1a** as the logo clearspace unit, based on the lowercase `a` in the production wordmark. Keep at least one a-width to the left and right and one a-height above and below. No edge, trim, rule, photograph, card boundary, or neighboring logo should enter that space.

Minimum screen sizes from the foundation:

| Composition | Minimum |
| --- | ---: |
| Horizontal lockup | 150×50px |
| Vertical lockup | 94×93px |
| Glyph | 50×45px |

For the glyph, the controlling pyramid must remain at least 24px. Below these thresholds, give the artwork more room; do not condense, simplify, or redraw it.

## Surface selection

- Paper `#F5F5F8` or White: use **Color** by default.
- Navy `#0E0E21` or Raised `#242438`: use **Reversed** by default.
- Uncontrolled photography or pattern: first establish a solid approved Augur brand field rather than dropping the mark directly onto a busy surface.
- Never add a containing badge, keyline, shadow, glow, effect, tagline, rotation, distortion, or arbitrary recoloring.

Choose one composition for a surface and keep it. A header, favicon, and slide master can legitimately use different compositions; the same header should not alternate between horizontal and vertical lockups.

## Current delivery status

The brand foundation PDF embeds the logo examples as high-resolution PNG image objects with transparency, not as vector drawing paths. The files linked above are the embedded objects extracted losslessly with their original alpha masks and canvas dimensions preserved. They were not traced, cropped, recolored, resized, or recomposed.

This makes the recovered family suitable for the documentation identity and normal-size raster web placements. Scale these files down only; do not upscale them beyond their intrinsic resolution.

The foundation states that SVG variants exist upstream, but those vector masters are not embedded in the PDF. Do not auto-trace the recovered PNGs and present the result as an official SVG. A production vertical/reversed SVG already used by the reboot website independently corroborates the current logo geometry, but missing SVG compositions remain an upstream-format gap.
